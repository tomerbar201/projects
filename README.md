# Data Analysis Projects

This repository contains my data analysis projects.

## Projects

### [NYPD Stop-and-Frisk Analysis](./nypd_stop_and_frisk/)
An analysis of the 2024 NYPD Stop-and-Frisk dataset to quantify racial, geospatial, and temporal disparities in policing.

### [Basketball Shooting Simulations](./simulations/)
Monte Carlo simulations of a stochastic basketball shooting model to understand the evolution of a player's shooting probability.
