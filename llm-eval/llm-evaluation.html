LLM Code Generation Portfolio Project


Project Overview


This notebook presents an end-to-end pipeline for evaluating Python code generation with a Large Language Model on the MBPP benchmark.
 

Code Generation with Large Language Models



This notebook demonstrates a complete pipeline to evaluate how well a Large Language Model (LLM) can generate Python code from natural language descriptions. The benchmark used is MBPP (Mostly Basic Python Problems), which provides Python programming tasks with tests for correctness.

Workflow


1. Load and explore the MBPP dataset
2. Decide what information is provided to the model vs. held out for evaluation
3. Split test cases into prompt examples and evaluation checks
4. Implement code generation with Qwen2.5-Coder-1.5B-Instruct
5. Evaluate performance on 100 problems
6. Analyze failure modes and prompt iterations

- Note: This model size (1.5B parameters) is practical for CPU execution, and can still achieve strong results when prompts include informative example tests.
- Note: Generation may take time on CPU. GPU acceleration can significantly reduce runtime.

Evaluation Setup



Notice that we need to provide the LLM with:
1. The problem description (text)
2. Example test cases to demonstrate expected behavior - these also reveal the expected function signature

Looking at the dataset, you'll notice each problem has a test_list field containing multiple test cases. We will split these tests:
- First 2 tests from test_list: Use as examples in the prompt — these show the model the expected function name and behavior
- 3rd test from test_list: Hold back for evaluation — this tests if the model's code actually works

This way, we provide the model with enough information to understand the problem, but still have an unseen test to verify correctness.

Note: Even if your generated function code is correct, it will fail the tests if it doesn't match the required signature shown in the example tests.

# split_tests function
def split_tests(problem):
    """
    Split test_list into example tests and evaluation test.
    """
    valid = False
    eval_test = []
    
    tests = problem['test_list']
    example_tests = tests[:2]
    
    if len(tests) > 2:
        eval_test = [tests[2]]
        valid = True
        
    return example_tests, eval_test, valid

test_code(generated_code, test_cases): Runs generated code using exec(), then runs each assert statement. Returns (code_compiled, tests_passed).

# Helper function to test generated code
def test_code(generated_code, test_cases):
    """
    Test generated code against test cases.
    Returns: (code_compiled: bool, tests_passed: bool)
    """
    namespace = {}
    try:
        exec(generated_code, namespace)
    except:
        return False, False
    
    # Handle empty test cases
    if not test_cases:
        return True, False
    
    try:
        for test in test_cases:
            exec(test, namespace)
        return True, True
    except:
        return True, False

# generate_code implementation
import re

def generate_code(problem_text, example_tests, max_new_tokens=512):
    """
    Generate Python code for a given problem using Advanced Few-Shot Prompting.
    """
    messages = [
        {
            "role": "system", 
            "content": (
                "You are an expert Python programmer. Write a Python function that solves the given problem. "
                "CRITICAL INSTRUCTIONS:\n"
                "1. Return ONLY the valid Python code enclosed in ```python ... ``` markdown blocks.\n"
                "2. Always use the exact function name from the assert statements.\n"
                "3. Write EFFICIENT code. If the problem requires recursion, you MUST use @lru_cache(maxsize=None) to avoid Time Limit Exceeded errors.\n"
                "4. Handle edge cases properly."
            )
        },
        # --- ADVANCED FEW-SHOT EXAMPLE START ---
        {
            "role": "user",
            "content": (
                "Problem: Write a function to find the nth Fibonacci number.\n\n"
                "Example tests:\n"
                "1. assert fib(2) == 1\n"
                "2. assert fib(5) == 5\n\n"
                "Write the complete Python solution:"
            )
        },
        {
            "role": "assistant",
            "content": (
                "```python\n"
                "from functools import lru_cache\n\n"
                "@lru_cache(maxsize=None)\n"
                "def fib(n):\n"
                "    if n <= 0:\n"
                "        return 0\n"
                "    elif n == 1:\n"
                "        return 1\n"
                "    return fib(n-1) + fib(n-2)\n"
                "```"
            )
        },
        # --- ADVANCED FEW-SHOT EXAMPLE END ---
        {
            "role": "user", 
            "content": f"Problem: {problem_text}\n\nExample tests:\n1. {example_tests[0]}\n2. {example_tests[1]}\n\nWrite the complete Python solution:"
        }
    ]

    prompt = tokenizer.apply_chat_template(
        messages, 
        tokenize=False, 
        add_generation_prompt=True
    )
    model_inputs = tokenizer([prompt], return_tensors="pt").to(device)

    outputs = model.generate(
        **model_inputs,
        max_new_tokens=max_new_tokens,
        do_sample=False
    )
    
    response_text = tokenizer.decode(outputs[0][len(model_inputs.input_ids[0]):], skip_special_tokens=True)
    
    # Extract code using regex
    match = re.search(r'```python\s*(.*?)\s*```', response_text, re.DOTALL)
    if match:
        code = match.group(1)
    else:
        code = response_text.replace("```python", "").replace("```", "").strip()
        
    # Defensive Post-Processing: Inject common imports
    common_imports = "import math\nimport re\nimport collections\nimport itertools\nfrom functools import lru_cache\n\n"
    if "import math" not in code:
        code = common_imports + code
        
    return code.strip()
